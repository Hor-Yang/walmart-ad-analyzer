# 领星 × 沃尔玛广告自动化分析工具 (walmart-ad-analyzer)

> 本地运行的领星 ERP（LingXing）沃尔玛广告报表自动化分析与决策工具。运营人员只需从领星导出 Excel 广告报表并上传，工具即可在数秒内输出大盘健康度诊断、核心业务结论、SKU 多期走势监控以及按优先级排序的落地优化动作清单。

---

## 🌟 核心特性与最新升级

1. **SKU 智能映射系统（新增）**：
   - 支持上传自定义 SKU 映射表（`.xlsx` 或 `.csv`），自动将领星报表中的纯数字 `Item ID`（项目ID）替换为店铺真实 SKU。
   - 侧边栏提供标准的「📄 下载 SKU 映射表模板.xlsx」，支持运营一键导出填写并重新上传。
   - 全链路生效：商品位诊断、总动作清单、SKU 走势看板均自动同步显示对应 SKU。

2. **SKU / 商品每日及多期走势看板（新增）**：
   - **多期报表自动拼接**：支持在上传区同时多选上传不同日期（如按天、按周或按月导出）的广告列表报表，系统自动识别文件名或列中的日期并按时序无缝拼接。
   - **突变与异动诊断**：
     - 🚨 **异常变差**：自动捕获花费激增但 0 出单、ROAS 骤降跳水（跌幅>30%）、CPC 飙升等风险。
     - 🌟 **变好向好**：自动标记订单放量增长且 ROAS 优异的高潜明星款。
   - **双 Y 轴交互图表**：花费 ($) 与销售额 ($) 柱状对比 + 投产比 ROAS 趋势折线（带保本 ROAS 参考警戒线）。

3. **零配置自动识别 6 大报表**：
   - 依据文件名关键词自动识别：搜索词、关键词、广告活动、广告列表、平台、页面类型。
   - 彻底解决领星报表“每页插入重复汇总行（`-`）”的导出痛点，实现自动清洗与 100% 数据校验。
   - 自动修正口径：自动计算 `总销售额 = 直接销售额 + 关联销量额`（解决搜索词表原始广告销售额恒为 0 的问题）。

4. **极简 UI 与专业运营交互（优化）**：
   - 去除杂乱符号与生硬格式，整体排版偏向极简企业级风格，重点突出数字与业务行动。
   - 提供「运营决策内参」摘要卡片，分层汇总大盘、P0止血、P1扩量与流量位置建议。
   - 侧边栏增加「保本 / 目标 ACOS 警戒线」动态调节，快速定位侵蚀利润的广告活动与产品。

## 📂 报表与文件上传支持

### 1. 领星 6 张核心广告报表
- **搜索词报表**（文件名含 `搜索词`）：高损否词与高转化挖词。
- **关键词报表**（文件名含 `关键词`）：建议降价 20%、提价 15%、建议暂停与潜力恢复。
- **广告活动报表**（文件名含 `广告活动`）：Live 计划诊断与预算撞顶监控。
- **广告列表报表**（文件名含 `广告列表`）：商品位表现，支持单期或**多期多文件上传**。
- **平台报表**（文件名含 `平台`）：App、Mobile、Desktop 流量结构分析。
- **页面类型报表**（文件名含 `页面类型`）：Search、Browse、Item 等位置投产分析。

### 2. 可选映射与模板
- **SKU 映射表**：可直接使用侧边栏「下载 SKU 映射表模板」导出的 Excel，填入对应的 Item ID 与 SKU。

## 📊 主要分析功能导航

- **`🎯 总动作清单`（默认主页）**：聚合全部诊断建议，按 P0（今天做）、P1（本周调）、P2（观察优化）集中展示，支持一键导出 CSV。
- **`📈 SKU多期趋势`**：单品时序走势图、异动预警名单、全量 SKU 周期指标表。
- **`① 广告活动诊断`**：在投 Live 计划健康度诊断与标签系统，已暂停活动表现汇总。
- **`② 搜索词否词/挖词`**：清单 A（P0/P1 否词）、清单 B（出单词迁精准组出价建议）、清单 C（高点击无转化）。
- **`③ 关键词调价`**：展示建议降价 20%、建议提价 15%、建议暂停与误暂停恢复。
- **`④ 商品位诊断`**：跑量商品 TOP10、烧钱商品、竞价低于建议 30% 提示、状态异常拦截。
- **`⑤ 平台与页面位置`**：全景对比各端与各页面类型的花费占比与 ROAS，一键锁定裁剪点。
